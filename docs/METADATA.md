# metadata and attribution

The software is MIT-licensed. This does not grant a new license to the material
described by, or excerpted in, the research snapshot.

- GitHub records keep repository identity, public status, links, update times,
  topics, and the license identifier reported by GitHub. That identifier does
  not grant permission to copy code from a repository.
- arXiv records keep paper identity/version, authors, categories, dates, links,
  and abstracts. Follow each original paper for its license and full text.
- MathOverflow and Mathematics Stack Exchange question metadata preserves
  author attribution, the source permalink, and the content license reported
  by the API. Bodies and answers are not archived by this tool.
- Blog records keep titles, dates, the author, the source permalink, and a
  short attributed feed excerpt. The author retains rights to the article.

The review queue records the exact abstract excerpt and offsets used by the
open-language heuristic. It describes a source statement rather than an
independently verified mathematical fact.

The checked-in live snapshot came from the upstream repository. Its original
capture timestamp and per-source success times are preserved. Offline fixtures
are synthetic, prominently labeled, and kept separate from live captures.
